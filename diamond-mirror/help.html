• Controls: Click and right-click (within squares).
  • Clicking is, strictly speaking, all that is needed. Right-clicking allows for making auxiliary marks for notekeeping, but is not strictly needed. Hovering over lines highlights them, but is also not needed.
  • This is intended to be solved on computer (not phone).
  • Each button links to a puzzle. Brackets = size. Green = solved, yellow (and asterisk) = current.
  • Rules are not given, but the first row of puzzles (1-8) is intended as a tutorial.
  • State is saved in browser.
  • Checkbox controls answer checking. If off, puzzles will not turn green when solved.
  • Note that solved puzzles can still be edited, which will generally lead to them becoming unsolved.
