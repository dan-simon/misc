• Controls: Click and right-click. This is intended to be solved on computer (not phone).
  • Each button links to a puzzle. Brackets = size. Green = solved, yellow (and asterisk) = current.
  • Rules are not given, but the first row of puzzles (1-8) is intended as a tutorial.
  • State is saved in browser.
  • Checkbox controls answer checking. If off, there will be no indication of if a puzzle is solved or not (completely instructionless). If on, when a puzzle is solved, its state will freeze. (Turning answer checking off after solving puzzles can lead to strange display behaviors, e.g. puzzles displaying as solved but reverting when you open them. Having it off or on from the start should work well, though.)
